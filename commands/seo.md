# Technical SEO audit

Choose the intended public page types, current deployment and search property. Load engineering-craft's [technical-seo-audit](https://github.com/orocsy/engineering-craft) skill from its installed package or reviewed checkout. If unavailable, use current [Google Search Central documentation](https://developers.google.com/search/docs) and [Search Console Help](https://support.google.com/webmasters/). Run the audit and follow the approved [workflow route](../docs/WORKFLOW_ROUTES.md) to correct evidenced problems. Route loading and interaction findings through [perf](perf.md). Record each finding's website status and search platform status separately in the [delivery evidence](../docs/DELIVERY_EVIDENCE.md) record.
