```ts
// discount.service.ts (before)
computeCheckoutTotal(cart, customer, promo?) {
  let total = cart.subtotal;
  if (promo) total -= this.promoAmount(promo, cart.subtotal);          // promo off subtotal
  if (customer.loyaltyTier) {
    total -= this.loyaltyAmount(customer.loyaltyTier, cart.subtotal);  // ⚠ loyalty ALSO off the
  }                                                                    //   ORIGINAL subtotal
  return total;
}
```

Root cause: on the promo path, the loyalty amount is computed from the **pre-promo subtotal** and subtracted **in addition to** the promo — the two discounts stack, and because loyalty is percentage-of-original-subtotal the combined reduction can far exceed either discount alone ("way too high", only "sometimes" — i.e. only when a promo is present, which explains the intermittence).

const loyaltyOff = customer.loyaltyTier ? this.loyaltyAmount(customer.loyaltyTier, cart.subtotal) : 0;
